# 管理者限定の指導録音

試合詳細のスコアの下に「試合のメモ」と「指導の録音メモ」を表示します。PK欄の開閉とは独立しています。

1. 場面（ハーフタイム・試合前・試合後・その他）を選び、「録音を開始」を押します。
2. 「停止して文字起こし・要約」を押すと、既存の Gemini API で解析します。
3. 要約と文字起こしを確認・修正します。
4. 「音声・文字起こし・要約を保存」または「保存せず破棄」を選びます。

文字起こしに失敗しても「録音音声を保存」で元の音声を保存できます。
保存した記録を開き、「文字起こし・要約を作成」で再試行できます。
再試行でできた文章は管理者が確認して「文字起こし・要約を保存」を押すまで反映しません。
音声は重複保存せず、同じ記録に文章を追加します。

保存した記録は同じ試合の管理者画面で再生・閲覧・削除できます。
録音は1回10分・8MBまでです。録音中は画面を開いておいてください。
保存前の録音はブラウザーのメモリー内にあり、再読み込み・終了で消えます。
解析時は音声を Google の Gemini API へ送信します。保存ボタンを押すまではアプリの Drive に保存しません。

## 公開時の操作

このプロジェクトは **Vercel の画面と Google Apps Script の API を別々に公開**しています。
GitHub への push だけでは Apps Script の内容は更新されません。

1. [GAS の更新とデプロイ](gas-deploy.md) に従い、保存済みの Google 認証で既存の公開先を更新します。
   オンラインの `coach-voice-notes` と `コード` の呼び出し部分だけを更新し、他のファイルを保持します。
   `gas-readwrite (5).js` 全体でオンラインのメインスクリプトを置き換えません。
2. 既存のスクリプト プロパティ `GEMINI_API_KEY` を維持します。
   キーを HTML・GitHub・チャットに貼る必要はありません。
3. **実行ユーザーは所有者、アクセス設定と既存の /exec URL は維持**します。
   新しいアクセス権の承認が必要な場合だけ所有者が画面上で行います。
4. GitHub の画面側を公開し、管理者アカウントで試合詳細を開きます。
   以前からログインしている端末では、録音欄にログイン中の管理者のパスワードを入力して本人確認します。
5. 短い音声で録音→停止→文字起こし→要約の編集→保存→再読込→再生を確認します。
   一般メンバーでは録音欄が表示されず、管理者用 API へ直接送信しても取得できないことを確認します。

初期化用の `setup()` を再実行する必要はありません。

## 保存先と権限

- 初回保存時に、実行所有者の Google Drive に非公開の「塚口AFC 管理者限定 指導記録」フォルダーを作成します。
- 試合ごとの下位フォルダーに元の音声と、文字起こし・要約の JSON を保存します。
- 共有スプレッドシート、一般向け試合メモ、`getAll`、公開 URL には指導記録を含めません。
- 音声を読み込むときもサーバーが管理者の署名セッションを検証し、音声だけを返します。
- 共有されたフォルダー・ファイルは拒否します。保存先の共有設定は変更しないでください。
- 削除は音声と JSON を Drive のゴミ箱へ移動します。必要なら所有者が Drive から復元できます。
- サーバーで現在の `admin` / `super_admin` 権限を検証します。一般メンバーのユーザー ID を書き換えるだけでは取得できません。
- セッションの有効期間は7日間です。パスワード変更・降格・アカウント削除でも失効します。
- 通信失敗時に同じ保存ボタンを再度押しても、同じ記録を重複保存しません。

自動設定されるスクリプト プロパティ:

| 名前 | 用途 |
| --- | --- |
| `COACH_VOICE_SESSION_SECRET` | 管理者セッションの署名。公開しないでください。変更すると既存セッションが失効します。 |
| `COACH_VOICE_FOLDER_ID` | 非公開の保存先。初回保存時に自動作成します。 |

任意の `COACH_VOICE_MODEL` で Gemini モデルを変更できます。未設定時は既存の AI 機能と同じ `gemini-2.5-flash-lite` を使用します。

## 検証

依存パッケージの追加はありません。Node.js で実行できます。

```text
node tests/coach-voice.test.cjs
node tests/coach-voice-ui.test.cjs
node tests/tab-swipe.test.cjs
```

認証・権限失効・非公開保存・音声形式・保存失敗時の後始末・二重保存防止・試合間の分離・削除・一般データへの非混入と、録音から保存／破棄・保存後の文字起こし再試行、縦・横スクロールとタブ切り替えの干渉を検証します。
これらのテストでは実際のマイクや外部 AI への通信を使用しません。
