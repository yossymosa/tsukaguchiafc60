# 管理者専用 TimeTree 閲覧試作

Android の TimeTree で参加しているチームの共有カレンダーを、アプリの「日程」→「TimeTree」で確認します。
`admin` / `super_admin` だけに表示し、Google Apps Script 側でも署名・期限・現在の管理者権限を毎回確認します。
一般メンバーの ID / role を書き換えただけでは利用できません。

## 公開時に必要な更新

GitHub / Vercel の画面と Google Apps Script は別に公開しています。
**GitHub への push だけでは、TimeTree への接続は有効になりません。**

1. 現在使用中の Google Apps Script プロジェクトを開きます。
2. メインスクリプトを、このリポジトリーの `gas-readwrite (5).js` に更新して保存します。オンライン側に独自の未反映変更がある場合は先に差分を照合してください。
3. 「デプロイ」→「デプロイを管理」→現在の Web アプリを編集→「新バージョン」で更新します。
4. 既存の実行ユーザー・アクセス設定・`/exec` URL を維持します。初期化用の `setup()` / `setupSheets()` は再実行しません。
5. 公開アプリを再読み込みし、管理者で「日程」→「TimeTree」を開きます。

新しい API キーや環境変数の登録は不要です。認証情報をソース・GitHub・チャットに貼り付けません。

## 使い方

1. 以前からログインしている端末で本人確認が表示された場合は、**このアプリの管理者パスワード**で確認します。
2. 接続画面に **TimeTree に登録したメールアドレスとパスワード**を入力し、「TimeTreeに接続する」を押します。
3. 表示するチームのカレンダーを明示的に選び、「予定を表示する」を押します。
4. 予定をタップすると場所とメモを開けます。「今日以降」「過去の予定」「すべて」と検索で絞り込めます。
5. TimeTree の変更を確認するときは「予定を更新する」を押します。
6. 利用後は「接続を解除」で、このアプリが保持する接続を破棄できます。TimeTree 本体の予定やアカウントは変更しません。

接続できない場合は TimeTree Web 版で同じメールアドレスとパスワードを使ってログインできるか確認します。
Google / Apple 等の外部ログインだけを使っており、メールアドレス・パスワードでログインできないアカウントは試作の対象外です。

## 試作の範囲

- 非公式の Web エンドポイントを使用します。TimeTree の変更で停止する可能性があります。
- カレンダー一覧、予定のタイトル・日時・場所・メモを読み取ります。取得は手動更新です。
- 予定・コメント・カレンダーの作成、変更、削除は実装していません。
- このアプリの一般向け日程、試合、出欠、配車、お知らせ、`getAll` に TimeTree の予定を転記しません。
- 繰り返し予定は「原本」として分け、元の開始日と内容を表示します。繰り返しの日付展開・例外の統合は未対応です。実施日は TimeTree で確認してください。
- コメントの画像・添付ファイルは取得しません。1万文字を超えるメモは省略を明示します。
- 大量の予定や異常なページ送りは、途中の内容を全件と見せず取得エラーにします。

## 認証情報と保存

TimeTree のパスワードは Apps Script を経由して TimeTree の固定 HTTPS ログイン先へ送信するだけです。
パスワード、TimeTree の生 Cookie、予定をブラウザーの LocalStorage / SessionStorage、共有シート、Drive、スクリプトプロパティに保存しません。

TimeTree の Cookie は Apps Script のスクリプトキャッシュに最長6時間だけ保持します。
キーは管理者 ID と署名セッションの SHA-256 から生成し、別の管理者・別セッションへ渡しません。
CacheService は期限前に内容を破棄することがあるため、その場合も再接続が必要です。
TimeTree の Cookie はブラウザーに返しません。プロバイダーのエラー本文・パスワード・Cookie をログに出しません。
管理者の降格・パスワード変更・退会・署名の失効後は、保持中の接続も利用できません。

## 検証

```text
node tests/timetree.test.cjs
node tests/timetree-ui.test.cjs
```

外部通信を置き換え、権限の偽装、セッションの分離・期限・解除、ページ送り、削除済み予定、認証失敗、秘密情報の非公開、画面の操作を検証します。
実際の TimeTree アカウントでの接続は、GAS の更新後に管理者自身の接続操作で検証してください。
