# 表示と動きの基準

配色・角丸・影・時間は `app-motion.css` の `:root` を基準にします。

- 本文は `--ink`、見出し・主要ボタンは `--navy`、操作の強調は `--blue`。
- 補足の文字は `--muted` / `--muted-soft`。小さい文字を薄いグレーで読みにくくしません。
- 面は白と淡いグレー、区切りは `--line` / `--line-soft`。勝敗・出欠・相手チームの色は意味を保ちます。
- 入力・通常ボタンは10px、カードは16px、モーダルは22pxの角丸。スイッチは丸い形にします。
- 影はカードと主要な操作に限定し、カードの中の要素すべてには付けません。
- 押下は140ms、切り替えは240ms、画面の登場は320ms。大きな跳ね返りや長い待ちを作りません。
- タップの演出はクリック確定後だけに表示し、スクロール開始時に除去します。
- 「動きを減らす」設定ではアニメーション・押下時の縮小を無効にします。
- 機能が未登録の画面は共通の `EmptyState` を使います。
- セグメントの選択は `aria-pressed`、スイッチは `aria-checked` で見た目と状態を合わせます。

一般ユーザー向けの設定非表示、TimeTreeの一時非表示、ゴール編集のタップ判定は維持します。
操作上の区別が必要な色やサイズは、共通化のために一括で上書きしません。
